# Drape

Upload photos of your clothes. Each day the app shows one outfit to wear.

## What you can do

- **Closet** — add tops, pants, shawls, slippers and earrings (photo + name)
- **Today** — see one outfit. Tap the arrow for another outfit. Tap the tick if you will wear it.
- **Week** — see Monday to Friday

Your data stays on your phone. No login is needed.

## Run the app

```bash
flutter pub get
flutter run
```

On this computer you can also use:

```bash
flutter run -d chrome
```

## First time

1. Enter your name
2. Open Closet
3. Add your tops, then add pants (one pant can go with two or three tops)
4. Open Today

To make an Android file:

```bash
flutter build apk --release
```

The file is:

`build/app/outputs/flutter-apk/app-release.apk`
